# Changes

Release notes by day, newest first (generated by `scripts/changelog.py` from the git history and `scripts/changelog_overrides.json`; do not edit by hand). Each day lists highlights first, then improvements, fixes and documentation.

## 2026-11-15

### Highlights

- The garage exit steers around garage walls automatically, using the walls read from each track's own collision meshes (--box-yaw-bias auto); all 34 layouts pass (`c7892ea`)

### Improvements

- gtr2-lap-check --all-cars together with --all-layouts runs every car at every layout (`aa9daa4`)
- Each car's garage start is recorded per layout; jolts with a mostly vertical signature are logged as BUMP (`c7892ea`)

### Fixes

- The garage-mouth lip at Zhuhai 4 no longer jolts the car: the straight run out of the box is a walking-pace roll (2 m/s) with no brake, and a vertical jolt in the garage exit no longer makes a run unclean (`e8be99f`)

### Documentation

- Record the post-fix garage-exit checks and the dropped merge-turn model (`750305c`)
- To-do: investigate the Zhuhai 4 garage bump (`241f186`)

## 2026-11-14

### Highlights

- The wheel profile includes throttle, brake and clutch pedals (8-bit, the clutch is a pedal axis, not a key) (`b64052e`)
- Stick and wheel are now different input profiles: the wheel limits steering speed over 900 degrees of rotation and reports in 14-bit steps; the stick keeps the tuned behaviour (`3e6f114`)
- The car moves 40% sooner after DRIVE: 9.2 s down to 5.6 s (shorter gear step, bounded cockpit wait) (`e705f28`)
- Select the wheel in the game's control mappings automatically (!SELECTWHEEL, wheel presets, gtr2-select-wheel.py) and drive with --input wheel (`c90717c`)

### Improvements

- Readers for the game's .gtr archives and .gmt meshes, and an offline garage wall map that predicts a garage exit hit without running the game (`256a936`)
- gtr2-recover.py: one command to clean up after an interrupted run (stale nav servers, orphaned game, launcher, game folder) (`b64052e`)
- Axis probe measures how the game processes vJoy axes (dead zone, sensitivity and centre are identity by default); driver script override and ; separator for --profile (`9b0274f`)
- Garage-exit check (--garage-exit): stops 2 s after merging onto the pit lane so every car's exit can be tested in about 35 s; all 24 cars pass at Imola (`c2dd936`)
- Start-up stages from DRIVE to first movement are timed (STAGE lines) so changes can be measured (`e0100e6`)

### Fixes

- Anderstorp 3 garage exit no longer clips the pillar between the bays (first as a per-layout heading bias, replaced by the automatic planner) (`73537db`)
- The Controls page is recognised again when the wheel is selected (`b64052e`)

### Documentation

- List the garage map tests in CLAUDE.md (`1db55aa`)
