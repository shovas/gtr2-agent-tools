# Changes

Notes for users of the tools, by day, newest first (generated by `scripts/changelog.py` from the git history and `scripts/changelog_overrides.json`; do not edit by hand). Each day lists highlights first, then improvements, fixes and documentation. The detailed, agent-level changes are in the git history (`git log`).
