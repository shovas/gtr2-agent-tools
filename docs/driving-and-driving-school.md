## Hands-free driving and the Time Trial lap save (2026-11-10)

**Result: a Time Trial lap was driven by script and saved; the file landed in this install and nothing touched `Documents\GTR2`.** Imola GP 2004, Lamborghini Murcielago, lap 2:51.604 (the dash showed 2:51.6); `Persistent` ticked; SAVE in the TIMETRIAL tab offered "<profile> - 2_51_604" and wrote `TimeTrial\Imola\<profile> - 2_51_604.GTT` (170,149 bytes). `Documents\GTR2\TimeTrial` stayed empty and the launcher reported "nothing else touched Documents\GTR2".

**The tool: `scripts/gtr2-drive-lap.py`** (standard library only today, by habit not by rule; run with `python -I`). It is a rewrite of the earlier harness's tuned `drive_map.py` control loop (pure pursuit on the AIW racing line, corner speeds from the bends ahead, throttle/brake duty cycles, gears from rpm, `--fast` preset: 60 m/s, 7.5 lateral, 6.0 braking, 6th gear) without numpy, PIL or the earlier harness's test harness. `scripts/gtr2_driving/telemetry.py` and `trackmap.py` are copies of the earlier harness's modules (read from that folder, not modified there; `trackmap` has a changed ROOT). Usage: `python -I scripts\gtr2-drive-lap.py --aiw GameData\Locations\Imola\4Imol.AIW --fast [--pit-aim -3] [--laps-crossed 2] [--dry-run]`. It checks the game window is in front before every key press and aborts if not; it stops after the lap counter advances `--laps-crossed` times, after 8 s without movement, or `--total` seconds. Run it from a normal PowerShell, with the PC left alone.

**Everything that went wrong first, so nobody repeats it:**
1. **Key timing.** The earlier harness's `gtr2ctl.cmd_key` waits `hold` ms after the key-UP as well as after the key-down, so every pulse is half down, half up; its duty cycles and steering gains were tuned with that. Releasing at once doubled the effective steering and throttle and overshot the turn out of the garage by 70 degrees. `press_key` here copies the double wait.
2. **Profile.** The `<profile>` profile binds driving to a joystick. The test profile edit (done with the game closed, byte-preserving regex replacement, reverted with `git checkout -- UserData`) copied from the earlier harness's profile: `Basic Controls=1`, `Shift Mode=0`, `Auto Reverse=0`, `Opposite Lock=0`, `Speed Sensitive Steering=0.6`, `Steer Ratio Speed=25`, `Difficulty Type=2` and `Control - Accelerate=(0, 30)`, `Brake=(0, 44)`, `Steer Left=(0, 51)`, `Steer Right=(0, 52)`, `Shift Up=(0, 56)`, `Shift Down=(0, 184)`, `First Gear=(1, 152)`. Time acceleration (K) is separate.
3. **Car and layout.** The proven setup is the Murcielago (`Profile Vehicle File`, `Vehicle File`, `Reserved Vehicle File` = `GAMEDATA\TEAMS\GT\LAMBORGHINI MURCIELAGO TEAMS\DAMS\04024_GT_MURC.CAR`) and `Track File`/`Track Description`/`AI Database File` pointing at the layout (the earlier harness's `drive_all.py` does the same edits). The Gillet Vertigo in this profile starts differently and, in Time Trial, hit the pit-exit marshal.
4. **Open Practice validates the port.** Same car and track: the car leaves the garage box (start x=-152, z=410, 11.6 m off the line, heading error +60 as in the earlier harness's log), runs the pit lane at 16 m/s, joins the circuit and laps clean (zero off-road samples, max offset 5.0 m): lap counter 0 to 1 at 199.7 s and 1 to 2 at 371.1 s, a **171.4 s** lap (earlier harness: 172 to 176 s).
5. **Time Trial starts differently.** After DRIVE the game puts the car on the **main straight (about x=207, z=382), already rolling at about 13 m/s in 3rd**, heading for the pit entry, and parks it in its box by itself within roughly 15 s (engine off, gear 0, rpm 0; telemetry then reads that stale position). The driver therefore starts on whichever of the pit lane or racing line is nearer (the racing line here) and skips the first-gear step when the car is moving; press DRIVE and start the driver immediately. With the pit lane route the Time Trial marshal and a car in the exit lane stopped the Gillet, and the Murcielago stopped nose-first at the wall.
6. **Lap timing.** The first start/finish crossing after DRIVE starts timing (the telemetry lap counter stays 0); the second crossing completes the lap (counter 0 to 1, dash "last lap" shows the time). The SAVE button turns on only after that; `Persistent` did not auto-save here.
7. **Menu facts learned:** the Time Trial pause menu is Continue, Restart, Return to Garage, Replay, Hide Menu (no Autopilot); the **I** key (`Toggle AI Control`) does nothing in Time Trial, with `No AI Control` set to 0 as well; Skip outlap is locked inside the session; the DRIVE button needs a second click when the first only hovers; in the cockpit there is no LEAVE EVENT, use Esc, Return to Garage (Enter on the highlighted row), then LEAVE EVENT (130,688) and its tick (1056,359).

**Still untested:** Driving School challenge progress (needs a lesson-specific start, not attempted), other machines. A second `GTR2.exe` crashes while one runs (see above), so the launcher's overlap handling is only relevant between runs.

So with the relative-path config **Driving School progress stays in this folder**.

**Why the earlier attempts failed, so nobody repeats it:** (1) I had reverted the keyboard profile with git between sessions, so a later launch had the joystick bindings (header `MODE: NOVICE` instead of `SIMULATION`) and the keys did nothing; re-apply the profile (see the driving section) with the game closed. Level n in the list is at client (130, 177 + (n-1) x 18); the game returns to the challenge list by itself after the result screen.
- **Levels 1, 2 and 3 (dry): GOLD** (Level 1 earlier at 0:13.914; Levels 2 and 3 in this session). Level 2's first run glitched (repeated shifts into 3rd, 85 m travelled, no pass) and a plain retry took GOLD, so expect about one failure in three from shift/input glitches; just retry.
